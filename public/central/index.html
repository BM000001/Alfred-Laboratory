Como a versão real funcionará

O GitHub será a fonte verificável de Issues, PRs, commits e testes. Os marcos de cada entrega serão separados: definido, código publicado, CI, teste no iPhone e aprovação. Uma PR aberta nunca será mostrada como concluída.

Acesso privado via Google, sincronização automática, capturas reais, alertas e controle de agentes dependem de uma arquitetura autenticada e ainda não estão disponíveis. Este protótipo não solicita senhas nem tokens.
